## COLUMN DEFINITIONS

### Core Columns

**Date**: When you made the contact (5/12 = May 12)

**Company**: Prospect company name

**Contact Name**: Decision maker's name (First Last + Initial if needed)

**Tier**: T1, T2, T3 (from prospect list)

**Annual Spend**: KES amount from prospect list (e.g., KES 500M)

**Contact Method**: 
- Email
- LinkedIn (connection request + message)
- LinkedIn (DM only, after connection accepted)
- Phone
- In-person meeting

**Message/Template Used**: Which template did you use?
- Template 1A (Tier 1 - High Budget)
- Template 2A (Tier 2 - Operations Focus)
- Template 3A (Tier 3 - Specialized)
- Template 5A (Follow-up - 48h)
- Template 5B (Follow-up - Post LinkedIn)
- Custom (describe what you wrote)

**Subject Line**: Email subject line used (helps track what resonates)

**Send Time**: What time did you send? (helps identify best outreach times)

**Response Status**: 
- No response yet
- Email opened (if tracked)
- Email clicked (if tracked)
- Responded via email
- Responded via LinkedIn
- Called back
- No response (5+ days passed)

**Response Type**: 
- Positive (interested, wants to talk)
- Neutral (will think about it, not sure yet)
- Negative (not interested, decline)
- Auto-reply (out of office, will get back)

**Follow-up Date**: When should you follow up if no response?
- 5/15 (3 days after initial email)
- 5/20 (after initial email + LinkedIn + phone)

**Notes**: 
- Specific pain points they mentioned
- Constraints (budget cycle, approval needed)
- Reasons for rejection (wrong time, already have solution)
- Positive signals (excited about concept, want pilot)
- Action items (send materials, get CEO approval)

**Status**: 
- Emailed (sent initial email)
- Connected (accepted LinkedIn connection)
- Interested (positive response, considering)
- Call Scheduled (confirmed call date/time)
- Pilot Agreed (said yes to pilot)
- Not Interested (declined)
- Nurture (keep in pipeline, wrong timing)

## QUICK SETUP INSTRUCTIONS

### Create the Sheets (15 minutes)

1. **Go to Google Sheets** → sheets.google.com
2. **Create new spreadsheet** → Name it: "Sokogate Sales Tracking - Week 1"
3. **Create 5 sheets** (tabs at bottom):
   - Sheet 1: "Daily Outreach Log"
   - Sheet 2: "Weekly Summary"
   - Sheet 3: "Engagement Tracker"
   - Sheet 4: "Upcoming Calls"
   - Sheet 5: "KPI Dashboard"

4. **Copy templates above into each sheet**

5. **Add formatting** (optional):
   - Header row: Bold + light blue background
   - Freeze top row (View → Freeze → 1 row)
   - Set column widths (drag column borders)
   - Add conditional formatting: Status "Interested" = highlight green

6. **Share with your team**:
   - Click Share → Add email addresses
   - Permission: "Editor" (so team can update)

### Daily Use (5 minutes)

1. **Every morning**: Check Daily Outreach Log
   - Filter Status = "Call Scheduled" → confirm calls on calendar
   - Filter Response Status = "Pending" → note any responses overnight
   - Identify today's outreach targets

2. **After each action**: Update immediately
   - Sent email → add row, update Status to "Emailed"
   - Prospect responds → update Response Status + Notes
   - Scheduled call → add to Sheet 4 + calendar

3. **Friday EOD**: Update Weekly Summary
   - Count totals for each metric
   - Calculate conversion rates
   - Note key wins
   - Plan next week

## TEMPLATE FORMULAS (Optional - For Google Sheets Power Users)

### Calculate Response Rate
```
=COUNTIF(Daily!D:D,"Positive") / COUNTA(Daily!A:A)
```

### Calculate Days to Response
```
=AVERAGE(Daily!J:J - Daily!I:I)
```

### Sum Total Outreach
```
=COUNTA(Daily!A:A) - 1
```

These will auto-calculate as you add data!
